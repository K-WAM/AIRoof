Client Onboarding Guide

Step-by-step instructions to take a new signed client from zero to live calls — covering Vapi, the portal, phone numbers, and go-live verification.

Overview — What You're Setting Up

Vapi (voice platform)

  • One AI assistant per client
  • 7 tools attached: bookAppointment, createLead, escalateCall, checkAvailability, lookupAppointment, cancelAppointment, getCurrentDate
  • One phone number (new or forwarded)
  • Webhook URL pointing to our server

Portal (Firestore + UI)

  • One business document with their config
  • Vapi assistant ID linked so calls route correctly
  • Branding (logo URL, brand color, contact phone)
  • Client login provisioned so they can see their dashboard

Phase 1 — Create the Vapi Assistant

Go to dashboard.vapi.ai → Assistants → + Create Assistant

  1. 1
    Name the assistant

    Use the receptionist name from the industry template (see Industry Quick Reference). E.g. "Alice" for roofing, "Claire" for HVAC, "Aria" for dental.

  2. 2
    Set the First Message (greeting)

    Example: "Thanks for calling [Company Name], this is Alice. How can I help you today?"

  3. 3
    Set the System Prompt

    Use the prompt generated from our portal (see Phase 2). For now set a placeholder — you'll update it after the portal generates the real config.

  4. 4
    Configure the model

    Provider: OpenAI — Model: gpt-4o-mini — Temperature: 0.5 — Max tokens: 150

  5. 5
    Configure voice (TTS)

    Provider: Cartesia — Voice: Sonic 3.5 "Ariana - kind friend" (~250ms latency, excellent for phone). Alternatively: ElevenLabs Flash for maximum voice realism at slightly higher latency.

  6. 6
    Configure transcription (STT)

    Provider: Deepgram — Model: nova-3 — Endpointing: 300ms

  7. 7
    Set the Server URL (Advanced tab)

    https://ai-roof.vercel.app/api/webhooks/vapi

    Set the webhook secret: generate a strong random string, set it as VAPI_WEBHOOK_SECRET in Vercel, then paste the same value into the Secret field in the Vapi dashboard under Advanced → Server URL. The webhook now requires a valid secret — the former VAPI_AUTH_BYPASS workaround was removed (T-010, fail-closed auth).

  8. 8
    Add all 7 tools

    Go to the Tools tab → + Add Tool and add each (they already exist in your Vapi account — search and select):

    bookAppointment   createLead   escalateCall   checkAvailability   lookupAppointment   cancelAppointment   getCurrentDate

  9. 9
    Save and copy the Assistant ID

    After saving, the assistant ID appears in the URL bar and assistant settings. Looks like: 9267a84a-0f4f-416b-a328-1dc539f5265e

    Copy it — you'll need it in Phase 2.

Phase 2 — Set Up the Phone Number

Option A — New Vapi number (recommended)

  1. Vapi dashboard → Phone Numbers → + Buy Number
  2. Search by area code (use client's local area code)
  3. Select the number → assign to the assistant you just created
  4. Copy the Phone Number ID (starts with pn_)
  5. Give the client this number to use as their business line, or forward their existing number to it

Option B — Forward existing number

  1. Client keeps their existing number
  2. Set up call forwarding on their carrier to forward to the Vapi number
  3. Most carriers: dial *72 + [Vapi number] to enable forwarding
  4. Test by calling the client's original number — AI should answer
  5. Unconditional forward: all calls go to AI. Conditional: only unanswered calls.
Recommended for most clients: Buy a new local Vapi number + set conditional forwarding (forward on no-answer after 2 rings) from their existing number. This way staff can still answer — if they don't, the AI catches it.

Phase 3 — Create the Business in the Portal

Go to https://ai-roof.vercel.app/admin/onboarding

  1. 1
    Step 1 — Company Profile

    Business name: Exact legal or trade name (e.g. "Roof Doctors South Florida")

    Business ID: Lowercase, hyphens only (e.g. roof-doctors-sf) — permanent, choose carefully

    Owner email: The email they'll use to log in

    Main phone: Their business phone number

    Service area: Comma-separated cities

  2. 2
    Step 2 — Template and Plan

    Industry: select the matching vertical (Roofing, HVAC, Dental, Landscaping, General Contractors, Property Management). This pre-fills services, FAQs, emergency rules, and agent personality from the template.

    Receptionist name: use the industry default or customize (e.g. "Alice" for roofing).

  3. 3
    Step 3 — Services and FAQs

    Review the auto-filled template defaults. Adjust any services or FAQs the client specifically requested.

  4. 4
    Step 4 — Rules and Routing

    Escalation phone: Owner's cell — called/texted for emergencies

    Notification email: Where appointment and lead emails are sent

    Review emergency rules and booking rules — adjust for client-specific policies

  5. 5
    Step 5 — Vapi and Branding

    Vapi assistant ID: Paste the ID from Phase 1 Step 9

    Vapi phone number ID: Paste the pn_ ID from Phase 2

    Brand color: Their primary hex color (e.g. #1e3a5f)

    Contact phone: The number shown on confirmation emails

    Logo URL: HTTPS link to their logo image (optional but recommended)

  6. 6
    Click "Create company"

    The portal creates the Firestore document. The AI will now route calls to this business automatically via the Vapi assistant ID.

Phase 4 — Provision Client Login

The client needs a Firebase Auth account + a businessUsers document to log in and see their dashboard.

  1. 1
    Use the onboarding wizard (automatic)

    If you entered the owner email in Phase 3 Step 1, the wizard creates the Firebase Auth account and businessUsers doc automatically. A temporary password and a password-reset welcome email are both generated — the password is shown once on the success screen, and the reset-email is sent to the owner's inbox via no-reply@luxordev.com (T-043).

  2. 2
    If provisioning manually (fallback)

    Firebase Console → Authentication → Users → Add User (email + temp password). Then Firestore → businessUsers/{uid}:

    uid: "their-firebase-uid" email: "their@email.com" businessId: "roof-doctors-sf" businessName: "Roof Doctors South Florida" role: "owner" superadmin: false
  3. 3
    Send them their login credentials

    Portal URL: https://ai-roof.vercel.app/login

    Email: their email | Temp password: from the wizard success screen (the owner also receives a password-reset welcome email from no-reply@luxordev.com)
