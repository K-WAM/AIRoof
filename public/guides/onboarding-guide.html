You get back to the job. We get you the booking.

Client Onboarding Guide

Step-by-step instructions to take a new signed client from zero to live calls — covering Vapi, the portal, phone numbers, and go-live verification.

Overview — What You're Setting Up

Vapi (voice platform)

  • One AI assistant per client
  • 5 tools attached (bookAppointment, createLead, escalateCall, checkAvailability, lookupAppointment)
  • One phone number (new or forwarded)
  • Webhook URL pointing to our server

Portal (Firestore + UI)

  • One business document with their config
  • Vapi assistant ID linked so calls route correctly
  • Branding (logo URL, brand color, contact phone)
  • Client login provisioned so they can see their dashboard

Phase 1 — Create the Vapi Assistant

Go to dashboard.vapi.ai → Assistants → + Create Assistant

  1. 1
    Name the assistant

    Use the receptionist name the client agreed on (e.g. "Alice", "Mia", "Riley"). This is what the AI introduces itself as.

  2. 2
    Set the First Message (greeting)

    Example: "Thanks for calling [Company Name], this is Alice. How can I help you today?"

  3. 3
    Set the System Prompt

    Use the prompt generated from our portal (see Phase 2). For now set a placeholder — you'll update it after the portal generates the real config.

  4. 4
    Configure the model

    Provider: OpenAI — Model: gpt-4o-mini — Temperature: 0.5 — Max tokens: 150

  5. 5
    Configure voice (TTS)

    Provider: ElevenLabs — Voice: Rachel (ID: 21m00Tcm4TlvDq8ikWAM) — Model: eleven_turbo_v2_5

    This gives the most natural, low-latency voice. Target latency is under 1.5 seconds.

  6. 6
    Configure transcription (STT)

    Provider: Deepgram — Model: nova-3 — Endpointing: 300ms

  7. 7
    Set the Server URL (Advanced tab)

    https://ai-roof.vercel.app/api/webhooks/vapi

    Leave the secret field blank while VAPI_AUTH_BYPASS=true is active.

  8. 8
    Add all 5 tools

    Go to the Tools tab → + Add Tool and add each of these (they already exist in your Vapi account — just search and select):

    bookAppointment   createLead   escalateCall   checkAvailability   lookupAppointment

  9. 9
    Save and copy the Assistant ID

    After saving, the assistant ID appears in the URL bar and in the assistant settings. It looks like: 9267a84a-0f4f-416b-a328-1dc539f5265e

    Copy it — you'll need it in Phase 2.

Phase 2 — Set Up the Phone Number

Option A — New Vapi number (recommended for new clients)

  1. Vapi dashboard → Phone Numbers → + Buy Number
  2. Search by area code (use client's local area code)
  3. Select the number → assign to the assistant you just created
  4. Copy the Phone Number ID (starts with pn_)
  5. Give the client this number to use as their business line, or set up a forward from their existing number

Option B — Forward existing number to Vapi

  1. Client keeps their existing number
  2. Set up call forwarding on their carrier to forward to the Vapi number you provisioned in Option A
  3. Most carriers: dial *72 + [Vapi number] to enable forwarding
  4. Test by calling the client's original number — Alice should answer
  5. Unconditional forward: all calls go to AI. Conditional forward: only unanswered calls.
Recommended for most clients: Buy a new local Vapi number + set conditional forwarding (forward on no-answer after 2 rings) from their existing number. This way staff can still answer — if they don't, the AI catches it.

Phase 3 — Create the Business in the Portal

Go to https://ai-roof.vercel.app/admin/onboarding

  1. 1
    Step 1 — Company Profile

    Business name: Exact legal or trade name (e.g. "Roof Doctors South Florida")

    Business ID: Lowercase, hyphens only (e.g. roof-doctors-sf) — this is permanent, choose carefully

    Owner email: The email they'll use to log in

    Main phone: Their business phone number

    Service area: Comma-separated cities (e.g. Miami, Coral Gables, Doral)

  2. 2
    Step 2 — Template and Plan

    Industry: Roofing (pre-fills services, FAQs, emergency rules)

    Receptionist name: agreed name (e.g. "Alice")

    Greeting: "Thanks for calling [Company Name], this is Alice. How can I help?"

  3. 3
    Step 3 — Services and FAQs

    Review the auto-filled roofing defaults. They will be used by the AI to answer service questions.

  4. 4
    Step 4 — Rules and Routing

    Escalation phone: Owner's cell — called/texted for emergencies

    Notification email: Where appointment and lead emails are sent

    Review emergency rules and booking rules — adjust if client has specific policies

  5. 5
    Step 5 — Vapi and Branding

    Vapi assistant ID: Paste the ID from Phase 1 Step 9

    Vapi phone number ID: Paste the pn_ ID from Phase 2

    Brand color: Their primary brand hex color (e.g. #1e3a5f)

    Contact phone: The number shown on confirmation emails

    Logo URL: HTTPS link to their logo image (optional but recommended)

  6. 6
    Click "Create company"

    The portal creates the Firestore document. The AI will now route calls to this business automatically via the Vapi assistant ID.

Phase 4 — Provision Client Login

The client needs a Firebase Auth account + a businessUsers document to log in and see their dashboard.

  1. 1
    Create their Firebase Auth account

    Go to Firebase Console → Authentication → Users → Add User. Enter their email + a temporary password. They can reset it after first login.

  2. 2
    Create their businessUsers document

    In Firestore → businessUsers/{their-uid} → create document with these fields:

    uid: "their-firebase-uid" email: "their@email.com" businessId: "roof-doctors-sf" businessName: "Roof Doctors South Florida" role: "owner" superadmin: false
  3. 3
    Send them their login credentials

    Portal URL: https://ai-roof.vercel.app/login

    Email: their email | Temp password: whatever you set

Phase 5 — Go-Live Testing (15 Minutes)

Run through this checklist before handing off to the client.

  1. 1
    Call the Vapi number directly

    Call the number assigned in Phase 2. Alice should answer with the correct greeting within 3 seconds.

    ✓ Correct company name in greeting   ✓ Receptionist name correct   ✓ No dead air

  2. 2
    Book a test appointment

    Say: "I need a roof inspection, I'm available next Tuesday morning at 10am."

    Provide a test name, phone, and address when asked. Alice should call bookAppointment and confirm.

    ✓ Appointment appears in portal at /company/appointments

    ✓ Notification email arrives at the configured notification address

  3. 3
    Test lead capture

    Call again. Say: "I just want to get some information about your services, not ready to book yet."

    Alice should capture as a lead. Check /company/leads in the portal.

  4. 4
    Test emergency escalation

    Call and say: "I have water coming through my ceiling right now."

    Alice should flag as urgent and trigger escalation. Check escalation email arrives at configured address.

  5. 5
    Test appointment lookup

    Call from the same number you used in test 2. Say: "I want to confirm my appointment."

    Alice should find the appointment by phone number and read back the details.

  6. 6
    Test client login

    Log in to the portal using the client's credentials. Confirm they see only their data — no other businesses visible.

    ✓ Dashboard shows call counts   ✓ Appointments tab shows test appointment   ✓ Leads tab shows test lead

  7. 7
    Send confirmation email

    On the Appointments page, click Send Confirmation on the test appointment.

    ✓ Email arrives with client's brand color and logo   ✓ Footer says "Powered by Luxor AI" (subtle)

All 7 tests passed? The client is live. Send them their login credentials and schedule a 15-minute walkthrough call to show them the dashboard.
